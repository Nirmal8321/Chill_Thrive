# Chill Thrive 🌊❄️

Chill Thrive is a wellness and recovery-focused website designed to promote
science-backed cold and heat therapy experiences.  
The project was built as part of **GWOC (GirlScript Winter of Code)** to
demonstrate frontend web development skills and clean project structure.

---

## 🌟 Features

- Modern and responsive UI
- Ice Bath, Steam, Jacuzzi & Combo therapy services
- Functional booking form (frontend)
- Awareness page explaining recovery science
- Founder & brand story page
- Gallery showcasing wellness experiences
- Clean navigation and consistent design
- Runs on a single local server using Live Server

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- VS Code (Live Server)

## ▶️ How to Run the Project

1. Open the project folder in **VS Code**
2. Install the **Live Server** extension
3. Right-click on `index.html`
4. Select **Open with Live Server**
5. Navigate through the website using the navbar
